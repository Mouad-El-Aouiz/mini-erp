# SEC-001 — Address Dependency Audit Findings

## Objective

Apply targeted dependency fixes without downgrading Next.js or Prisma, and verify the authentication flow after a reproducible installation.

## Changes

Scoped npm overrides select:

- `mysql2@3.24.5` under Better Auth and Prisma.
- `deepmerge-ts@8.0.2` under `@prisma/config`.

The lockfile records the resolved dependency graph. Overrides are temporary maintenance policies; review them when upstream packages adopt corrected versions. The deepmerge-ts update crosses a major version, so Prisma configuration, generation, and migrations must be checked before merging.

The application uses PostgreSQL. mysql2 is included transitively by its dependencies; the application does not configure a MySQL connection.

CI now runs `npm audit --omit=dev --audit-level=high` after installation. This checks npm's production dependency graph, not every tool installed by CI, and does not replace a full dependency review.

## Advisories

- [mysql2 cleartext authentication issue](https://github.com/advisories/GHSA-3f6p-5ww8-9rcr): fixed in 3.22.0.
- [mysql2 compressed-packet resource exhaustion](https://github.com/advisories/GHSA-rgwj-5xj2-c3m3): fixed in 3.23.1.
- [deepmerge-ts recursive object resource exhaustion](https://github.com/advisories/GHSA-ggr8-5vv4-36mx): fixed in 8.0.0.
- [deepmerge-ts version 8 release notes](https://github.com/RebeccaStevens/deepmerge-ts/releases/tag/v8.0.0): compatibility changes require validation.

## Remaining Finding

[braces stack exhaustion advisory](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm) lists no patched release as of 2026-10-07. The dependency path is:

`eslint-config-next → @next/eslint-plugin-next → fast-glob → micromatch → braces`

This path belongs to the lint tooling. The repository supplies its lint patterns; no application endpoint accepts brace patterns for this tool. That reduces the known exposure but does not prove the package safe for arbitrary input.

Keep the finding visible in full audits and recheck for an upstream fix. Do not suppress it, substitute an unrelated package, or use npm audit fix --force to downgrade the framework. Production-only auditing deliberately excludes development-only dependencies; it does not resolve this finding.

## Validation

Recorded locally on 2026-10-07 with Node.js 22.23.2 and npm 10.9.8:

- `npm ci` passed with the committed dependency policy and updated lockfile.
- `npm ls mysql2 deepmerge-ts` confirmed mysql2 3.24.5 and deepmerge-ts 8.0.2 under the intended parents.
- Full audit decreased from nine high entries to five, all linked to the remaining braces advisory. Entries include affected ancestor packages, not five independent root vulnerabilities.
- `npm audit --omit=dev --audit-level=high` passed with zero reported vulnerabilities in npm's production graph.
- Prisma validation and client generation passed.
- Both migrations applied to a fresh isolated PostgreSQL 18 test database.
- Database connection check, TypeScript, ESLint, and production build passed.
- All six existing Chromium authentication tests passed (20.0 seconds).
- The test database contained zero users, sessions, and accounts after fixture cleanup; the disposable test service and its volumes were removed.
- `git diff --check` passed.

These checks cover the project's PostgreSQL configuration and existing authentication behavior; they do not certify every upstream feature affected by a major dependency override. GitHub Actions must still pass on the pull request.
